Is implementing alloca(3) in C really impossible?
2023-07-13

`alloca` is a function provided by several C libraries (e.g. glibc) that lets
you allocate a block of memory that will be freed when the calling function
exits. It's usually done by allocating memory on the stack.

But here are a couple of questions:

* No C standard or POSIX standard mentions `alloca`, so what "should" it really
  do?

* Given that no C standard mentions the stack, is it even possible to implement
  `alloca` in C, or do you need assembly to move the stack pointer?

* Given that compiling code with `-fomit-frame-pointer` usually results in
  addresses being expressed as relative to the stack pointer, is it safe to
  move the stack pointer ourselves?

TL;DR: The answer is that you need special support from the compiler to
implement `alloca` and you can't do it yourself, in C or assembly.
