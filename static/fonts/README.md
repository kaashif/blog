# Latin Modern webfonts

Latin Modern is based on Computer Modern, the traditional LaTeX typeface.
These four WOFF2 files come from the LaTeX.css project:
https://github.com/vincentdoerig/latex-css/tree/master/fonts

The fonts are distributed under the GUST Font License, included as
`GUST-FONT-LICENSE.txt`. The LaTeX.css MIT license is also included.

Upstream Latin Modern project: https://www.gust.org.pl/projects/e-foundry/latin-modern
